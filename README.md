# Pixiv Previewer Plus

Pixiv Previewer Plus 是 Ocrosoft 所作 Pixiv Previewer 的衍生版本。它在上游 3.8.7 的基础上把按收藏数排序扩展到用户页与收藏页，
并增加了不依赖排序的收藏数徽章。本仓库只用于发布，Greasy Fork 上的脚本由本仓库同步。

## 安装

在已安装 Tampermonkey 的浏览器中打开下列 Greasy Fork 脚本页面并点击安装。

https://greasyfork.org/zh-CN/scripts/599015-pixiv-previewer-plus

该脚本在 Greasy Fork 上为未列出类型，不出现在脚本列表与搜索结果中，只能凭上述地址安装与更新。

安装前请禁用上游的 Pixiv Previewer。两者共用 pixiv 页面中的同一份设置存储，同时启用会互相覆盖设置。
脚本的设置与收藏数缓存保存在各浏览器本地，不随脚本同步。
